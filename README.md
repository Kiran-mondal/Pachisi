# Pachisi: The Ancient Indian Epic 🎲

Welcome to the digital recreation of **Pachisi (Chaupar)**, the traditional and royal board game of ancient India. This project is not just a game, but a journey back in time, featuring an ancient aesthetic combined with modern web technologies. 

It also includes a built-in portfolio section to showcase my other development projects.

## 🌟 Features
- **Ancient Indian Theme:** Royal red, gold, and parchment aesthetics with traditional fonts.
- **Traditional Rules:** Playable with traditional wooden dice (1, 3, 4, 6 and doublets).
- **Responsive Design:** Playable on both desktop and mobile devices.
- **Developer Portfolio:** An integrated "My Projects" modal to showcase other works.
- **Future Integration:** Ready to be connected with Serverless Postgres (Neon DB) for saving game states and leaderboards.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **Backend/Database:** Node.js, Neon Database (Upcoming)
- **Deployment:** GitHub Pages / Vercel (Upcoming)
