## 📜 About The Project

**Bharatiya Pasha** is a modern, fully responsive web recreation of the ancient Indian epic board games—**Pachisi** and **Chaupar**. Traditionally played by Maharajas and Royals of ancient India, this game brings a 5,000-year-old heritage directly to your browser with stunning 3D aesthetics and advanced logic.

Whether you want to play a friendly game of Pachisi with safe zones or engage in a ruthless strategic battle in Chaupar mode, this project delivers a highly immersive and customizable experience.

---

## ✨ Spectacular Features

*   🎲 **True 3D Pasha (Stick Dice):** Realistic solid wooden stick dice tumbling inside a 3D oval wooden bowl, built purely with CSS 3D transforms.
*   🔮 **3D Realistic Marble Tokens:** Pawns designed to look like shiny, reflective glass marbles that rest in custom "Token Yards" for each player.
*   ⚔️ **Dual Game Modes:**
    *   **Pachisi:** Classic rules with "Safe Zones" (marked with a star).
    *   **Chaupar:** Hardcore epic mode where safe zones are disabled, and capturing can happen anywhere!
*   🎨 **Custom Player Setup:** Select your preferred colors! You don't have to stick to Red vs. Black; choose any combination (Red, Green, Yellow, Black).
*   🤖 **Human vs. Bot AI:** Play locally with friends or challenge the integrated Computer Bot.
*   📱 **Fully Responsive UI:** Seamless layout scaling for Desktops, Tablets, and Mobile phones.

---

## 🛠️ Tech Stack

This project is built using modern front-end web technologies with zero external dependencies (No React, No Canvas libraries):

*   **HTML5:** Semantic structure and layout.
*   **CSS3 (Advanced):** Grid & Flexbox architectures, 3D Transforms (`perspective`, `rotate3d`), CSS Animations, and Custom CSS Variables for the Royal Theme.
*   **Vanilla JavaScript (ES6+):** Core game logic, turn management, path mapping, capturing mechanics, and DOM manipulations.

📖 Game Rules Summary
 * Setup: 2 to 4 players can join. Each player has 4 tokens in their respective Token Yard.
 * Movement: Roll the Pasha to move around the cross-shaped board. The number rolled corresponds to the number of steps. Doublets grant an extra turn!
 * Capturing: Landing exactly on an opponent's token captures it, sending it back to their Yard and granting the attacker an extra turn.
 * Winning: The first player to safely navigate all 4 tokens around the board and into the "HOME" square wins the game.
